# 三体：黑暗森林 - 预编译游戏

## 文件说明

### `three-body-game.json`
预编译的《三体：黑暗森林》互动叙事游戏文件。包含 98 个场景、4 个属性系统（生命值、理智值、信任度、真相认知），完整还原了《三体》小说的核心剧情。

**如何加载：**
1. 启动 Genesis Sandbox 应用
2. 进入「游戏」或「Play」模式
3. 选择「加载游戏」或「导入」
4. 选择 `public/games/three-body-game.json` 文件
5. 开始游戏

### 游戏特色
- 完整还原三体第一部《地球往事》的核心剧情
- 玩家扮演国家安全局特工，调查科学家连环自杀案
- 逐步揭开三体文明、智子、ETO、黑暗森林理论的真相
- 4 个属性系统影响剧情走向和结局
- 超过 30 种不同的结局
- 包含叶文洁、汪淼、史强、常伟思等原著角色

# 三体世界设定集 - 世界书

## 文件说明

### `three-body-worldbook.txt`
完整的《三体》世界观设定集，可用于 Genesis Chat 的「世界书」功能。

**如何使用：**
1. 启动 Genesis Sandbox 应用
2. 进入「Genesis Chat」模式
3. 打开「世界书」面板
4. 点击「上传」或「导入」
5. 选择 `public/worldbooks/three-body-worldbook.txt` 文件
6. AI 将基于三体世界观生成互动故事

### 世界书包含内容
- 三体星系与三体星的环境设定
- 三体文明的生理特征（脱水/浸泡机制）
- 三体社会结构与科技水平
- 智子（Sophon）的原理与功能
- 红岸基地与叶文洁的故事
- ETO（地球三体组织）的派系
- 黑暗森林理论与猜疑链
- 面壁计划的核心概念
- 主要人物介绍

## 关于《三体》

《三体》是刘慈欣创作的科幻小说系列，由《三体》、《黑暗森林》、《死神永生》三部曲组成。该系列被誉为中国科幻文学的里程碑之作，讲述了地球人类文明和三体文明在宇宙中的兴衰历程，以及宇宙中残酷的黑暗森林法则。

本游戏和世界书基于《三体》第一部《地球往事》的核心设定创作。
